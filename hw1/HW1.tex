\subsubsection*{Handling the discontinuity in $\text{sinc}(0)$}
The unnormalized sinc function $\text{sinc}(x) = \frac{\sin(x)}{x}$ has a singular, pointwise (and thus removeable) discontinuity at $x=0$, where its two-sided limit is $1$. If we evaluate $\sin(0)/0$ directly, we acquire an IEEE 754 \texttt{NaN} error from $0/0$ floating-point division. To prevent such floating-point exceptions and avoid any cancellation errors near $x=0$, we compute $\text{sinc}(x)$ for values of $x$ sufficient small, $|x| < 10^{-4}$, via a second-order Taylor series:
\begin{equation}
\text{sinc}(x) ≈ 1 - \frac{x^2}{6}
\end{equation}
I specifically chose this, without any additional precision as one might imagine, as the truncation error is bounded by $\frac{x⁴}{120} ≤ \frac{(10^{-4})⁴}{120} ≈ 8.33 ⋅ 10^{-19}$, well below the precision ($ε≈ 2.22 ⋅ 10^{-16}$). Points outside this threshold use standard division. We simply need to check if something is in this bound, then divide.
